# Credit Consumption Prediction — ML Regression

Regression model to predict average credit card spend 
for the next 3 months for a leading bank.

## Business Problem
A bank wants to predict future credit card consumption 
for each customer to enable personalised marketing 
and risk management.

## What I Did
- Merged customer demographics, behavioural transaction 
  data, and credit consumption target variable
- Performed EDA and feature engineering
- Built regression model to predict cc_cons (target)
- Evaluated using RMSPE (Root Mean Square 
  Percentage Error)
- Generated predictions for customers with 
  missing target values

## Tools
Python · Pandas · NumPy · Scikit-learn · Matplotlib
